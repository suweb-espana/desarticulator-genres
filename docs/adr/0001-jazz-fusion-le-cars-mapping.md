# Jazz Fusion MIDI is written for Le Cars loaded notes

Jazz Fusion targets the Rock Foundry SDX Le Cars preset, not generic GM percussion.
Closed hat on beat 3 replaces the record's open hat because Le Cars hats are 18" crashes.
Toms use 48, 47, 43, 41 (high to floor); the shared BasePattern tom names are inverted for this kit.
Notes 46, 52, and 55 are not used: 46 washes, 52 is a crash not a china, 55 is unloaded.

**Considered Options**:
- Play Vinnie's open hat on 46 and accept the wash
- Keep BasePattern tom notes 43/45/48 and name them high/mid/low
- Use GM china 52 and splash 55 for fusion color

**Consequences**:
MIDI files are Le Cars-specific. A jazz ride kit or a correctly ordered GM map will still play, but tom melody and cymbal color will differ.
